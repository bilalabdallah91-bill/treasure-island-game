# 🏝️ Treasure Island - Text Adventure Game

An interactive text-based adventure game built with Python! Players navigate through decisions using doors and boxes to find the hidden treasure while avoiding traps.

---

## 🛠️ Concepts Applied
* Nested Conditional Statements (if / elif / else)
* String Normalization (.lower())
* User Input Handling (input())
* Multi-line Strings & Formatting
